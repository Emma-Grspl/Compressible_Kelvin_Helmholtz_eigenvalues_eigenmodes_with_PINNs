# Part I -- Subsonic spectral branches

This directory is the scientific companion for the subsonic part of a
compressible Kelvin--Helmholtz study. It contains the validated classical
reference, the piecewise-local neural atlas, production checkpoints, article
assets, and the light-weight code paths needed to inspect the published
workflow.

## Physical problem

The compressible Kelvin--Helmholtz instability is formulated as a non-self-
adjoint eigenvalue problem. Part I considers its subsonic regime, where the
growth-rate branch is established with a classical Riccati shooting reference.
The reference is compared with digitized Blumen isolines and is used to assess
both spectral and modal quantities.

## Method

The final workflow separates numerical roles deliberately:

1. Sparse spectral anchors identify the branch.
2. A **piecewise-local neural atlas**, formed of **locally continuous neural
   charts**, constrains the direct neural mode with physics.
3. **Deterministic routing** selects the relevant chart for a query point.
4. The **direct neural mode** and scalar estimate guide **scalar-guided GEP
   eigenpair selection** after an independent dense GEP diagonalization.
5. The reported discrete result is the **selected GEP eigenvalue/eigenvector**;
   the **classical Riccati shooting reference** remains independent.

The fixed-Mach physics-only experiment is retained as a branch-identification
failure baseline. It does not establish that physics alone interpolates
`c_i` reliably, and direct neural predictions do not replace either the
classical reference or the selected GEP eigenpair.

## Main results

The repository preserves a validated subsonic Riccati shooting map, the
49-chart production atlas with the `N340` sparse-anchor budget, fixed-Mach
spectral/modal audits, and the 17 curated manuscript assets. Detailed scope
and validation provenance are recorded in [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md)
and [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md).

## Installation

From `Part_I/`, create an environment appropriate for the target CPU/GPU
platform and install the tracked dependency list:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
export PYTHONPATH="$PWD/code${PYTHONPATH:+:$PYTHONPATH}"
```

The public requirements are intentionally not version-pinned. Reproduce the
documented HPC environment when exact platform compatibility is required.

## Quick start

Run a small classical eigenvalue calculation:

```bash
python examples/01_classical_eigenvalue.py
```

Inspect deterministic chart routing without loading a checkpoint:

```bash
python examples/02_query_neural_atlas.py
```

See [examples/README.md](examples/README.md) for details.
