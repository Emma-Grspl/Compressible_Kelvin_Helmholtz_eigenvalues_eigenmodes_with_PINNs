# Provenance

This directory records migration decisions, public-repository exclusions,
integrity inventories, and complementary-audit traceability for Part I.
It is provenance material, not an active numerical implementation.

The authoritative active subsonic code is under `../code/`; curated scientific
assets and processed inputs are under `../assets/`; and final numerical outputs
are under `../results/`. Historical source paths may appear in these records
without becoming active execution dependencies.
