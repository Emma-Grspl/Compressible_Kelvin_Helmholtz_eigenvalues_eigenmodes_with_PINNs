# Scientific results

This directory contains tracked numerical outputs, validation tables, and
processed results for the Part I subsonic study. It includes complementary
audits and representation or normalization ablations retained for scientific
traceability.

Canonical reusable inputs and publication-facing assets are under `../assets/`.
The figure manifest in `../article/FIGURE_MANIFEST.csv` identifies which
processed result is associated with each curated article figure. This directory
contains data, not the authoritative solver or training implementation.
