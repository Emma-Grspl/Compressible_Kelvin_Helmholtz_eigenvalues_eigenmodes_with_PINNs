# Experiment families

This directory preserves outputs by scientific experiment rather than only
by file format. Canonical reusable inputs are in `assets/`, checkpoints are in
`models_saved/`, and executable code is in `code/`.

`legacy_gep/` contains historical supersonic generalized-eigenvalue studies.
The final hybrid method is PINN-seeded Riccati shooting, not PINN-seeded GEP.
