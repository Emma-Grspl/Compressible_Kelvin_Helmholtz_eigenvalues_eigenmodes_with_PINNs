# Classical supersonic assets

This directory contains the scientific assets distributed with the complete
reproducible classical supersonic reference bundle.

The curated reference-v2 assets are stored in:

- `reference_v2/ci/`: principal spectral-growth figures;
- `reference_v2/modes/`: representative modal-field figures and PDFs;
- `reference_v2/tables/`: compact reference tables.

The scripts, configurations, tests, source data and reproducibility material
used to generate and validate these assets are located in the parent
`classic_supersonic/` directory.
