# Classical supersonic reference — selected assets

This directory is the lightweight visual showcase for the classical
supersonic Kelvin–Helmholtz reference.

The selected assets are located in `reference_v2/`:

- `ci/`: principal spectral-growth figures;
- `modes/`: representative modal-field figures and PDFs;
- `tables/`: compact reference tables;
- `README.md`: scientific interpretation and validation caveats.

This directory intentionally contains no solver code, campaign scripts,
complete modal dataset or internal validation tooling.

The complete reproducible bundle is located in `classic_supersonic/`.
