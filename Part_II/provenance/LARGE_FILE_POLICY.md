# Large-file policy

Audit date: 2026-08-27.

## Decision

Two complete modal CSV exports exceed GitHub's normal per-blob limit and are
new Git blobs. They remain available in the local worktree but are excluded by
two exact root `.gitignore` rules. No general CSV or assets rule is used, and
Git LFS is not enabled.

Both exports are reproducible packaging outputs:

- the raw-confirmed export is produced from the versioned confirmed/frozen
  modal reference by `code/scripts/evaluation/freeze_supersonic_v2_assets_and_code.py`
  and `code/scripts/evaluation/package_supersonic_sparse_reference_v2_final_freeze.py`;
- the tail-polished export is generated by
  `code/scripts/evaluation/polish_supersonic_v2_left_tails.py`, frozen, then
  packaged by the same final-freeze script.

Each local file has 838,847 data rows and the same modal schema as its legacy
counterpart. Compact Parquet regression data, metadata, checksums, producer
scripts, and legacy/frozen source material remain versioned. No active runtime
code refers to either migrated `table_...` path exactly, so normal execution
does not depend exclusively on these local-only copies.

See `provenance/LARGE_FILE_AUDIT.csv` for sizes, hashes, producers, equivalents,
and runtime-reference counts.
