# Scientific results

This directory contains processed supersonic validation outputs and
reviewer-control results, including branch-localization, physics-residual,
threshold-sensitivity, multiseed, computational-cost, routing, and Blumen
comparison records.

These are scientific outputs, not the source of the solver implementation.
Reusable inputs and canonical figure sources are under `../assets/`; active
experiment-family inputs and outputs remain under `../experiments/` and are
documented there because current scripts reference that location directly.
